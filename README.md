# CerviScreen AI — Option A

Static interactive educational cervical screening demo. Open `index.html` in a browser. Select a fictional patient, choose a public CDC cervical photograph or a local test image, run simulated analysis, and view or print a demo report.

## Image source
[CDC Public Health Image Library image 4413](https://wwwn.cdc.gov/phil/Details.aspx?pid=4413), also on [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:PHIL_4413_lores.jpg). Public-domain CDC photograph depicting cervical carcinoma. The sample loads remotely from Wikimedia Commons; internet is required.

## Safety
Educational prototype only. No AI inference, segmentation, diagnosis, risk assessment, or clinical decision support is performed. Report output is fixed, unrelated to the image. Do not use real patient data. Local images stay in the browser.

## Publish
GitHub repository Settings → Pages → Deploy from a branch → main → / (root). GitHub Pages eligibility for a private repository depends on account settings and plan.
